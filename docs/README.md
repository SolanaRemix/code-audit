# Audit Certificate Examples

This directory contains audit certificates generated by the CyberAi.network automated audit system.

## Certificate Structure

Each audit generates two files:
1. `audit_certificate.md` - Human-readable certificate
2. `audit_certificate_metadata.json` - Machine-readable metadata

## Certificate Components

### Header Information
- Certificate ID (UUID)
- Issue date and validity period
- Audit status (PASSED/FAILED/PENDING)

### Repository Details
- Repository name
- Branch name
- Commit SHA
- Commit hash (short)

### Security Analysis
- CodeQL scan results
- Vulnerability summary
- Code quality metrics
- Best practices compliance

### Verification
- Digital signature (SHA-256 hash)
- Verification instructions
- Status badges

## Example Workflow

1. **Code pushed/PR created** → Workflow triggers
2. **Security scan runs** → CodeQL analysis
3. **Audit executes** → Security checks performed
4. **Certificate generated** → Unique ID assigned
5. **Labels applied** → PR tagged with status
6. **Artifacts uploaded** → Certificate stored (90 days)

## Accessing Certificates

### From GitHub Actions
1. Go to Actions tab
2. Select workflow run
3. Download artifacts section

### From PR Comments
Each PR receives a comment with:
- Audit status
- Certificate ID
- Quick summary
- Link to full certificate

## Certificate Verification

To verify a certificate's authenticity:

```bash
# 1. Check the certificate ID matches the workflow run
# 2. Verify the commit SHA
git log --oneline | grep <commit-hash>

# 3. Compare the certificate hash with metadata
cat audit_certificate_metadata.json | jq '.certificate_hash'
```

## Retention Policy

- Certificates are stored as artifacts for **90 days**
- Historical audit data can be retrieved from workflow runs
- Metadata provides quick lookup of audit results

## Integration Examples

### Badge in README
```markdown
![Audit Status](https://img.shields.io/badge/audit-passed-brightgreen)
```

### CI/CD Integration
```yaml
- name: Check Audit Status
  run: |
    if [ -f docs/audit_certificate_metadata.json ]; then
      status=$(jq -r '.status' docs/audit_certificate_metadata.json)
      if [ "$status" != "passed" ]; then
        echo "Audit failed!"
        exit 1
      fi
    fi
```
